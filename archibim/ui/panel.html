NEW · Native SketchUp linework

Convert lines to BIM walls

Draw with SketchUp Line (L) on a single horizontal plane. Select one edge or an enclosed face. ArchiBIM finds the connected chain, merges straight segments, recognises corners and T-junctions, and splits crossings into linked branches.

Uses current wall thickness, height and alignment on the active level. Source lines stay untouched. Mixed-height / sloping edges, overlaps and walls under 50 mm are rejected. Complex 3-way junctions without a through-line are flagged for review.

Wall connection defaults

Corner and internal T-junctions now default to Linked. You can set any junction to Join Only or Unlinked in Wall Properties. Legacy Join Only junctions retain their prior setting until you explicitly link them.

BIM Scale protection

When the Scale operation finishes, ArchiBIM rebuilds length/plan dimensions while restoring specified wall thickness, window sizes, and heights. This creates a separate undo step. For complex shear, use the diagnostic repair tool instead.

Testing & repair

Rebuild geometry

Reapply saved specifications resets any distorted group scale to 1,1,1 and regenerates the BIM object from its stored dimensions. Adopt native Scale keeps the new horizontal length/footprint while restoring unscaled thickness, door/window sizes and heights. Both commands are undoable.

Stair & floor coordination

Recalculate stair openings

Synchronises upper floor slab cutouts with all stairs that have Auto-cut enabled. Use after manually moving groups in SketchUp.

Session diagnostics

Export testing log

Every Create, Edit, Rebuild and error writes an event to a local JSONL log. Export now includes the full wall connection graph, face-offset measurements, exact world reference-line positions, broken links, unmatched wall endpoints, SketchUp version, and recent errors. No screenshots or files are uploaded automatically.

Native SketchUp Scale cannot be intercepted safely during a Scale operation. Use Repair after Scale immediately afterward. Mirrored and skewed components should be tested on a copy.

IFC handoff

Drawing set · preview

Generate coordinated plans and elevations

Creates or updates floor/roof plans, four elevations, two central building sections and both available floor RCP previews. Uses native SketchUp scenes for LayOut. A second level is created only when a level exists; sections require manual placement and RCPs need ceiling objects.

Documentation

Plan scene

Creates a plan scene with a section cut at 1200 mm above the selected level and an orthographic top view. Dimensions, hatches and LayOut sheets are not automatic.

Proportional plan resizing

Resize BIM footprint

Changes wall runs, footprint and host positions while keeping wall thickness, door/window sizes and element heights. Test on a copy first. This is an explicit parametric command, not automatic interception of SketchUp's native Scale tool.

Automatic two-wall miters and single-branch T-cuts are preliminary. Multi-way joins, dissimilar-level joins, true family types and full IFC interoperability require further development and desktop testing.
