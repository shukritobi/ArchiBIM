Testing & repair

Rebuild geometry

Reapply saved specifications resets any distorted group scale to 1,1,1 and regenerates the BIM object from its stored dimensions. Adopt native Scale keeps the new horizontal length/footprint while restoring unscaled thickness, door/window sizes and heights. Both commands are undoable.

Session diagnostics

Export testing log

Every Create, Edit, Rebuild and error writes an event to a local JSONL log. Export generates a text file with SketchUp version, parametric attributes, transform scale factors and recent errors. No screenshots or files are uploaded automatically.

Native SketchUp Scale cannot be intercepted safely during a Scale operation. Use Repair after Scale immediately afterward. Mirrored and skewed components should be tested on a copy.
Deliverables

Schedules and model data

CSV is suitable for Excel. JSON retains element metadata, levels, settings and takeoff details.

Open BIM

IFC handoff

Uses SketchUp's native IFC exporter where available (normally SketchUp Pro). IFC type assignment also depends on having the IFC classification schema loaded. Always verify the resulting file in an independent IFC viewer.

Documentation

Plan scene

Creates a plan scene with a section cut at 1200 mm above the selected level and an orthographic top view. Dimensions, hatches and LayOut sheets are not automatic.

Proportional plan resizing

Resize BIM footprint

Changes wall runs, footprint and host positions while keeping wall thickness, door/window sizes and element heights. Test on a copy first. This is an explicit parametric command, not automatic interception of SketchUp's native Scale tool.

Automatic two-wall miters and single-branch T-cuts are preliminary. Multi-way joins, dissimilar-level joins, true family types and full IFC interoperability require further development and desktop testing.
